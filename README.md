## Klasyfikacja binarna i wieloklasowa

### Cel

Celem ćwiczenia jest przeprowadzenie badań związanych z klasyfikacją binarną i wieloklasową z użyciem regresji logistycznej na wybranych zbiorach danych: Titanic (przewidywanie przeżycia pasażerów) i Iris (klasyfikacja gatunków irysów).

### Zbiór danych

**a) Titanic** — zawiera dane pasażerów statku Titanic. Zmienna celu to `Survived`, która wskazuje, czy pasażer przeżył (1), czy nie (0). Dane obejmują m.in. wiek, klasę, płeć, liczbę członków rodziny na pokładzie i cenę biletu.

**b) Iris** — klasyczny zbiór danych z informacjami o trzech gatunkach irysów (*setosa, versicolor, virginica*), opisanych cechami morfologicznymi: długością i szerokością płatków oraz działek kielicha.
